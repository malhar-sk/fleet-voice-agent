Live mode streams your mic over WebRTC to a Pipecat pipeline (VAD → Whisper → LLM + tools → Piper). If it connects but you hear nothing (WebRTC media can't cross an SSH tunnel or Docker Desktop's NAT), use Hold to talk: it records while you hold the button and sends the clip over plain HTTP. The browser needs microphone permission (Chrome on localhost is fine). Demonstration only, synthetic data.
